Задание 1

Делю фронтенд на 4 части:
- host содержит в себе общие блоки для работы приложения (Main.js, App.js, Footer.js, Header.js, PopupWithForm.js)
- auth - всё, что относится к процессу авторизации и аутентификации (Login.js, Register.js, InfoTooltip.js, ProtectedRoute.js), localhost:8083
- cards - функционал работы с фотографиями (Card.js, AddPlacePopup.js, ImagePopup.js), localhost:8082
- users - функционал работы с профилем пользователя (EditAvatarPopup.js, EditProfilePopup.js), localhost:8081

Задание 2
./task2.drawio

Auth-сервис — можно взять сторонний модуль, так как он не является ключевым для бизнеса. Например, Keycloak.
Регистрируем пользователей, назначаем им роли, аутентифицируем запросы и перенаправляем в соответствующий микрофронтенд в зависимости от роли

Сервис нотификаций — тоже может быть сторонним модулем, срабатывает автоматически в зависимости от происходящих в системе событий

Admin panel — микрофронтенд для администраторов. Можно работать с заявками на апелляции, аукционами, услугами и товарами пользователей

Support panel — микрофронтенд для службы поддержки. Можно работать с заявками на техподдержку.

Панель покупателя — можно размещать заказы, оплачивать их

Панель продавца — можно размещать товары, услуги, аукционы, получать статистику платежей и покупателей

Сервисы, разделенные по бизнес-логике:
- сервис заявок на апелляцию
- сервис аукционов
- сервис товаров
- сервис услуг
- сервис заказов
- сервис платежей
- сервис аналитики
